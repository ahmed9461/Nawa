# Nawa

Nawa is a lightweight, private-first Android app for running local GGUF language models directly on-device.

The project is being bootstrapped from a clean repository. Its UI direction is adapted from the strongest parts of Nexora's chat experience, while the inference stack is intentionally local and based on the official llama.cpp Android binding.

See `PROJECT_STATUS.md`, `ROADMAP.md`, and `plans/` for current progress.
